# Rev.A 差分：1クリック出力を0→±127へ変更

## 対象
EC12E2420801（24クリック）、WeAct CH552 Core Board V1.0、USB HID Gamepad X軸。

## 変更
- 旧: クリック出力を「+127/-127→0」として扱う。
- 新: **クリック開始時に0を明示的にHID送信し、25ms以上保持してから+127/-127をHID送信する**。この立ち上がりを1カウントとする。
- 最大値を35ms以上保持したのち0へ戻して次のクリックを再アームする（次のカウントではない）。
- USBエンドポイントがBUSYのときには再試行する。最大値送信の成功が確認できるまでFIFOのクリックを消費しない。
- マイコン・ピン割当・F1/F2/PTT・VID/PIDおよびUSBレポート形式は変更しない。

## ホストテスト（実機ではない）
- `tools/test_firmware_mock.py`: 順序、最低保持時間、連続24クリック、USB送信失敗リトライ、キーON/OFF。
- `tools/test_usb_spec.py`: HIDディスクリプタと生成スクリプトの静的検査（実際のCH55xDuino上流コード未使用）。
- `tests/test_rotary_event.cpp`: 4遷移1クリックとFIFO管理。

## 制限
Chrome/WebTRXのGamepad APIはポーリングであり、アプリ側で中立→最大値を検出しなければ1クリック1カウントにはならない。CH552実コンパイル、書込、Windows列挙、WebTRX連携と実機の回転方向は未検証。
